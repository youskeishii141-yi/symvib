# SymVib

**結晶・分子の振動モードを対称性 (群論) で解析するツール**

結晶・分子の振動モードを、対称性 (群論) に基づいて帰属・可視化するための
Python ツール群です。DFT フォノン計算を行わずに「どんな振動モードが存在し、
各原子がどの方向に動くか」を理解することに特化しています。Raman / 赤外スペク
トルのモード帰属の補助や、群論・振動分光の教育用途を想定しています。

振動数の絶対値は求めません (それは Gaussian / ORCA / Quantum ESPRESSO などの
量子化学・第一原理計算の役割です)。本ツールは対称性が決める「モードの種類・
縮退・活性・変位パターン」を扱います。

## 設計思想: 「対称性確定」と「網目推測」

各振動モードについて、その対称種 (既約表現) が空間内に 1 回だけ現れる場合
(m=1)、変位の部分空間は群論だけで一意に決まります (**厳密**)。縮退成分の
向きと全体の符号は任意です。同じ対称種が複数回
現れる場合 (m>1)、対称性だけでは方向が決まらず線形結合の自由度が残ります。
この場合は 1/d² バネ網目モデルによる**推測**方向を、その旨を明示して提示します。
真の固有ベクトルが必要なら量子化学計算へ進む、という切り分けです。

この「対称性適応モードと真の固有ベクトルの違い」を、分子と結晶の両方で一貫
した枠組みで体験できるのが特徴です。

### 補足: 量子化学計算で何が決まり、何が残るか

基準振動は、質量で重み付けした力の定数行列 (ヘッセ行列) の固有ベクトルです。
群論が決めるのは「この行列が既約表現ごとのブロックに分かれる」という**形**だけで、
行列要素の**値**については何も言いません。

- **m=1**: 縮退度 g (A・B なら 1、E なら 2、T なら 3) の対称種のブロックは g×g で、対称性を保つ調和力学行列は
  この空間内で固有値 × 単位行列になります。固有空間は力の定数の値によらず決まります。
- **m>1**: 全ブロックは (m·g)×(m·g) です。実型の既約表現では partner の基底を
  そろえると m×m の混合問題に帰着します (複素共役ペアは実空間で扱います)。
  m 個のコピーをどう混ぜるかは行列要素の実際の値で
  決まります。量子化学・第一原理計算はこの値を与えるので、調和近似の範囲では
  混合の自由度はなくなり、固有ベクトルが決まります。1/d² 網目モデルは、この値を
  粗い近似 (中心力のみ・曲げ剛性なし) で代用しているため「推測」扱いです。

例: H₂O の Γvib = 2A₁ + B₂ では、B₂ (逆対称伸縮) は m=1 で変位パターンが対称性
だけで決まります。A₁ は m=2 で、「対称伸縮」と「変角」の 2 つの SALC が力の定数に
応じて混ざります。どれだけ混ざるかは計算しないと分かりません。

ただし、計算しても次の点は残ります。

1. **縮退した対称種 (E, T など) の中での向き**: 縮退した空間の中では、どの直交基底を
   選んでも同じように正しい固有ベクトルです。これは物理的に本当に任意で、どんな計算
   でもなくなりません (計算プログラムの出力は、そのうちの一つをたまたま選んだものです)。
   m>1 の「別のコピー同士の混ざり」とは別の種類の自由度です。
2. **全体の符号 (±)** は常に任意です。
3. **計算レベルへの依存**: 汎関数・基底関数などの選び方で混合係数は変わります。
   同じ対称種の 2 本のモードの振動数が近いと、混ざり方は力の定数のわずかな差に敏感に
   なります (偶然に縮退すれば、その 2 本の間でもまた任意になります)。
4. **調和近似の外側**: 非調和性・フェルミ共鳴・結晶場や溶媒の影響まで含めると、
   「固有ベクトル」という描像自体が近似です。また実験では固有ベクトルを完全に直接
   測ることはできず、同位体シフトや中性子散乱強度などから部分的に検証できるだけです。

本リポジトリでは、結晶について QE 凍結フォノン (`qe_frozen_phonon.py`) がこの
「量子化学計算へ進む」経路にあたり、力から力の定数を求めて m>1 の混合まで決めます。

| 何が決めるか | 対象 | 扱い |
|---|---|---|
| 対称性 | モードの種類・縮退・活性、m=1 の変位パターン | 本ツールで厳密 |
| 力の定数の値 | m>1 の SALC の混合 | 網目モデルで推測 → 必要なら第一原理計算で決定 |
| (何も決めない) | 縮退空間内の向き・全体の符号 | どちらの方法でも任意 |

## 収録ツール

| 入口 | 対象 | 概要 |
|---|---|---|
| `vibration_gui.py` (配布版 `SymVib.exe`) | 分子・結晶 | GUI。モード一覧と 3D 表示 (変位矢印・アニメーション)、XSF/レポート保存。 |
| `molecule_vibration_analysis.py` | 孤立分子 | 点群に基づく分子振動解析 (CLI)。45 点群対応。 |
| `factor_group_analysis.py` | 結晶 (周期系) | 空間群の因子群解析 (CLI)。Γ 点の既約表現分解。 |
| `qe_frozen_phonon.py` | 結晶 (QE 連携) | 力ベースの Γ 点凍結フォノン (CLI; Quantum ESPRESSO)。 |

解析の本体はパッケージ `symvib/` にまとめてあり、CLI と GUI は
同じ関数 (`analyze_molecule` / `analyze_crystal`) を呼び出します。

### 1. 分子振動解析

CIF または xyz を入力すると、分子点群を自動判定し、内部振動モードを既約表現
(Mulliken 記号) でラベル付けします。各モードの Raman / 赤外活性、分極率テンソル
成分、そして各原子の変位ベクトルを XSF 形式 (VESTA 用) で出力します。

- **45 点群に対応**: Cn / Cnv / Cnh / Sn / Dn / Dnd / Dnh の各系列を n = 2〜8 で
  ほぼ網羅、立方群 T / Th / Td / O / Oh、正二十面体群 I / Ih、直線分子 C∞v / D∞h。
- 直線分子 (無限群) は、回転角の連続族を数値積分した真の連続群射影演算子で
  厳密に分解します (有限部分群への近似はしません)。
- 複素既約表現を持つ群 (Cn, Cnh, Sn, T, Th) は複素指標で正しく扱います。
- 実験・計算構造の小さな歪み (既定 0.1 Å まで) は、検出した点群で厳密に
  対称化してから解析します (`--tol` で変更可。対称化したことはレポートに明記)。

詳細は [docs/README_molecule.ja.md](docs/README_molecule.ja.md) を参照してください。

### 2. 結晶因子群解析

CIF を入力すると、空間群を判定し、Γ 点 (k=0) の格子振動を既約表現に分解します。
Mulliken ラベルの自動付与、偏光ラマン選択則、各モードの変位パターンの XSF 出力に
対応します。m>1 のモードにはネットワークモデルによる方向推測を提示します
([docs/README_stage1_directions.ja.md](docs/README_stage1_directions.ja.md))。

### 3. QE 凍結フォノン

Quantum ESPRESSO と連携し、力の計算に基づいて Γ 点フォノンを求めます。
変位入力の生成 (`generate`)、力からの解析 (`analyze`)、対称性検証 (`validate`) の
ワークフローを提供します。設定例は [examples/qe_config_example.json](examples/qe_config_example.json)、
詳細は [docs/README_frozen_phonon.ja.md](docs/README_frozen_phonon.ja.md) を参照してください。

## GUI 版

### 使う人 (配布版)

[Releases](https://github.com/youskeishii141-yi/symvib/releases) から
`SymVib.zip` をダウンロードして展開し、フォルダ内の `SymVib.exe` を
ダブルクリックします。Python のインストールは不要です。zip には本ツールのライセンス
(`LICENSE`)、説明書 (`README.md` / `README.ja.md`)、同梱しているライブラリのライセンス表示
(`THIRD_PARTY_LICENSES.txt`) も入っています。

1. 「開く…」で `.xyz` または `.cif` を選ぶ (拡張子で分子/結晶を自動選択。
   分子の CIF は「分子」に切り替えて「▶ 解析」)。「デモ」から水・黒鉛も試せます。
2. 左の一覧でモードを選ぶと、右に原子・結合・変位矢印が 3D 表示されます。
   **左ドラッグで回転、ホイールでズーム、右ドラッグで平行移動**。左下に結晶軸
   (a, b, c; 分子は x, y, z) の向きを表示します。結晶は入力ファイルの単位胞の中
   (境界上を含む) の原子をすべて表示し、像の原子も元の原子と同じように動きます。
   縮退モードは「縮退成分」で a/b/c を切り替え、「アニメーション」で振動させられます。
   結合は VESTA の既定と同じく、元素の組ごとの最大結合長の表 (pymatgen 同梱の
   VESTA 既定値) で判定します。表にない組 (Al–Al などの金属どうし) は結合を引きません。
   分子では、表にない組 (H–H など) も共有結合半径の和 × 1.25 以内なら結合とします。
   一覧の「関与サイト」は、そのモードで動きうる原子のサイト (元素 + Wyckoff 記号、
   例 `Al(c)`) です。対称性だけで決まる厳密な情報です。
3. 「XSF/VESTA 保存…」で形式 (VESTA のみ / XSF のみ / 両方) を選んで全モードを書き出し、
   「レポート保存…」でテキストレポートを保存します。`.vesta` は VESTA でそのまま開け、
   灰色の細い矢印 (矢印の中点が原子の中心、最大変位で中心から ±0.67 Å、分子は ±0.53 Å) と
   結合の設定まで書き込まれています。
4. 右上の「Language / 言語」で英語と日本語を切り替えられます (既定は英語。選んだ言語は
   次回の起動時にも使われます)。画面・レポートの両方が切り替わります。

縮退モード (E, T など) の成分 a, b, c は、対称性だけでは向きが決まりません (縮退した
空間の中でどう取り直しても同じく正しい)。表示する成分は、物質によらない次の共通規則で
選んでいます (物質ごとの設定や特別扱いはありません)。

1. 軸 1, 2, 3 (結晶は入力セルの a, b, c、分子は x, y, z) の順に、縮退空間の中で
   「全原子の変位のうちその軸方向の割合」が最大になる動きを採ります。
   既に採った成分とほぼ同じ向きなら、それと直交する残りの中で選び直します。
2. 軸だけでは決まらないとき (例: ルチルの Eg のように全原子が c 方向にだけ動く) は、
   原子を座標順に並べて残りの成分を決めます。
3. 符号は「成分を決めた軸の方向への変位の総和が正」にそろえます。

この規則は原子の並び順 (CIF の書き方) によらず、同じ構造なら常に同じ成分を出します。
黒鉛・ZnO の E1/E1u や立方晶の T1u のように軸に沿って動けるモードでは、成分 a は
軸 a に、成分 b は軸 b に完全に平行になります。そうでないモード (石英の E など) では
「軸 a に最もよく沿った動き」になり、矢印は軸と平行になるとは限りません。成分どうしは
直交するとは限りません (六方晶の a, b は 120°)。3D 表示の初期の向きも、セルの 3 本の軸が
どれも見やすい方位を結晶系によらず計算で選んでいます。

一覧の色は活性 (赤 = Raman, 青 = IR, 紫 = 両方, 灰 = 不活性) を表し、
「方向」列が「対称性確定 / 推測(網目)」の区別です。

## インストール (Python から使う場合)

Python 3.9 以上を推奨します。

```bash
git clone https://github.com/youskeishii141-yi/symvib.git
cd symvib
pip install -r requirements.txt
```

依存パッケージ: `numpy`, `pymatgen` (構造の読み込み・点群記号), `spglib`, `spgrep`
(結晶の対称性・既約表現), `matplotlib` (GUI の 3D 表示)。

## 使い方 (CLI)

```bash
# GUI
python vibration_gui.py

# 分子振動解析: 引数なしで水のデモ
python molecule_vibration_analysis.py
python molecule_vibration_analysis.py mymolecule.xyz --outdir out --tol 0.05

# 結晶因子群解析: 引数なしで黒鉛のデモ
python factor_group_analysis.py mycrystal.cif --symprec 1e-3

# 出力 (レポート) は英語が既定。日本語にするには --lang ja
python factor_group_analysis.py mycrystal.cif --lang ja

# 書き出す形式: both (既定) / xsf / vesta
python factor_group_analysis.py mycrystal.cif --format vesta
```

`modes_<名前>/` に各モードの `.vesta` と `.xsf` を出力します。`.vesta` はそのまま矢印付きで
開けます。`.xsf` は VESTA で開き、Properties → Vectors → Show vectors で矢印を表示します。
黒鉛の出力例を [examples/modes_graphite/](examples/modes_graphite/) に置いています。
VESTA については次の節を参照してください。

Python から直接使う場合:

```python
from symvib.molecule import analyze_molecule, load_molecule
result = analyze_molecule(*load_molecule("benzene.xyz"))
print(result.decomposition)          # Γvib = 2A1g + A2g + ...
for mode in result.modes:
    print(mode.label, mode.activity, mode.displacements[0])   # (N, 3) 変位
```

## VESTA (結晶構造の可視化ソフト) について

本ツールが書き出す振動モードのファイル (`.vesta`, `.xsf`) は、結晶構造可視化ソフト
**VESTA** (門馬綱一・泉富士夫) で開いて、原子の変位を矢印で 3D 表示するためのものです。
GUI 版の 3D 表示だけで足りる場合は VESTA は必要ありません。

- 入手: 公式サイト <https://jp-minerals.org/vesta/> から無償でダウンロードできます
  (Windows / macOS / Linux)。利用条件は公式サイトを参照してください。本ツールには
  VESTA を同梱していません。また、本ツールは VESTA の開発者とは関係のない独立したものです。
- `.vesta`: そのまま開くと、灰色の矢印 (各原子の変位) と結合の設定が反映された状態で表示されます。
- `.xsf`: 開いた後、Properties → Vectors → Show vectors で矢印を表示します。
- VESTA で作った図を論文などに使う場合は、VESTA の文献
  (K. Momma and F. Izumi, *J. Appl. Crystallogr.* **44**, 1272–1276 (2011)) の引用が求められています。
- GUI の 3D 表示の結合の判定には、VESTA の既定の結合長の表 (pymatgen に同梱されているもの) を
  使っています。

## CIF の読み込み

実在の CIF によくある次のケースに対応しています (読み込み時の扱いはレポートに注記されます)。

- 複数の構造を含む CIF → 原子座標を持つ最初のデータブロックを使用
- ラベルが元素記号でない (`Ti1`, `O2a`)、酸化数付き (`O-2`, `Si+4`)、不確かさ付きの数値 (`4.583(2)`)
- 部分占有: 同じ座標を占める複数のサイトを 1 つの仮想原子にまとめ、名前はラベルの連結
  (例 `Ti1` と `V2` → `Ti1V2`; 質量は占有率で平均)。単独サイトの部分占有は完全占有として扱う。
  同じ元素の重複記載 (対称操作で重なる位置に別ラベルで書かれた原子) は 1 つの原子にまとめる
- 実在しない元素記号 (`Wat`, `X` など) → 質量 1 amu の仮想原子として扱う
- 分数の座標 (`1/2`)、BOM 付きのファイル
- 対称操作の記載がない → Hall 記号、H-M 記号 (`P 21/n`, `F d -3 m :2`, ICSD の `Z`/`S`,
  菱面体軸の `R`)、番号の順に補う。原点の選び方などが記号から決まらないときは、
  原子が重なりすぎない (0.5 Å 以上離れる)・原子数が最も少ない設定を選ぶ (それもなければ P1)
- 入力のセルは conventional でも primitive (菱面体軸など) でも超格子でもよい。
  既約表現のラベル・ラマンテンソル成分は空間群の標準の設定 (Bilbao と同じ向き) で表す

仮想原子を含む構造は QE 凍結フォノンには使えません (秩序化した構造を入力してください)。

## 軸の取り方 (C2v / D2 / D2h 分子)

B1/B2 (C2v) や B1/B2/B3 (D2, D2h) のラベルは座標軸の取り方に依存します。
本ツールは Mulliken の推奨に従い、平面分子では分子面の法線を x 軸にとります
(C2v は z = C2 軸、D2/D2h は z = 最も多くの原子を通る C2 軸)。この取り方では
水は 2A₁ + B₂、ホルムアルデヒドは 3A₁ + B₁ + 2B₂ になります。採用した軸は
レポートに表示されます。

## 検証

`tests/` に回帰テストがあります (`pip install -r requirements-dev.txt` の後
`python -m pytest tests`)。文献値との一致に加え、コードの内部経路に頼らない独立検査
(`tests/invariants.py`) で、すべてのモードが「対称操作で閉じた既約表現の部分空間になって
いること」「並進・回転を含まないこと」「活性・ラマンテンソル成分が射影演算子と一致すること」
「Mulliken ラベルが Bilbao Crystallographic Server の点群表と一致すること」を確認しています。

- 分子: 水 2A₁ + B₂、ホルムアルデヒド 3A₁ + B₁ + 2B₂、エチレン、メタン、CO₂、HCN、C₂H₂、ベンゼン、
  SF₆、B₁₂H₁₂²⁻、C₆₀ (2Ag + 3T1g + 4T2g + 6Gg + 8Hg + Au + 4T1u + 5T2u + 6Gu + 7Hu)、PCl₅、
  フェロセン (D5h / D5d)、エタン、アレン、B(OH)₃ ほか。45 点群すべての指標表を群論的に検証
  (`tests/test_tables.py`)。
- 結晶: 33 物質 (7 晶系) の Raman / IR / 不活性モード数を文献値と照合 (`tests/test_literature.py`;
  出典は各項目に記載)。230 空間群・530 設定の合成構造を網羅 (`tests/sweep_space_groups.py`、
  結果は [docs/validation_space_groups.ja.md](docs/validation_space_groups.ja.md))。COD の実在 CIF を
  各空間群 1 件ずつ解析 (`tests/check_cod.py`、[docs/validation_cod.ja.md](docs/validation_cod.ja.md))。
  phonopy の既約表現とも一致。
- QE 凍結フォノン: 合成した pw.x 出力で generate → analyze を通し、全対角化と一致。

外部の参照データ (Bilbao の点群指標表、COD の CIF) は配布物に含めていません。取得しない
ままでもテストは通り、それらを使う照合だけがスキップされます。照合まで再現するには、
各公式サイトから取得してからテストを実行します (COD は `tests/data/cod/index.json` に記録した
ID と同じ CIF を取得します)。GitHub Actions の「Full validation」ワークフロー
(`.github/workflows/full-validation.yml`) でも同じことを手動実行できます。

```bash
python tests/fetch_bilbao_tables.py
python tests/fetch_cod.py
python -m pytest tests
python tests/check_cod.py          # COD の全 227 件 (時間がかかります)
python tests/sweep_space_groups.py # 230 空間群・530 設定の網羅
```

検査の詳細と見つかった誤りの一覧は [docs/validation_report.ja.md](docs/validation_report.ja.md)。

## 注意・制限

- 本ツールは**振動数の絶対値を計算しません**。モードの対称性・縮退・活性・
  変位パターンを対称性から決めるためのものです。
- 網目モデル (中心力バネ) は曲げの剛性を持たないため、平面分子の面外モードなど
  では m>1 の推測方向が任意になります。その場合はレポートに注記します
  (既約表現の同定自体は純群論で行うため影響しません)。
- 分子の CIF は単位胞内の原子をそのまま 1 分子として扱います。分子が胞の境界で
  切れていないファイルを使ってください。部分占有サイトを含む構造は扱えません。
- 収録外の点群が入力された場合は、振動モードの本数を表示したうえで、対称種
  ラベルは出力せずに安全に終了します。

  - 原子の対応付けが全単射でない (原子が重なっている) 場合に、黙って特異な表現を作らず
    エラーにする。
  - GUI: エラーログの保存先がエラーダイアログに表示されなかった。
- README に「量子化学計算で何が決まり、何が残るか」の補足を追加。

### v2.1 (公開前検査)
- 外部基準との照合を追加: Bilbao の 32 点群表、230 空間群 (530 設定) の網羅スイープ、COD の
  実在 CIF 227 件、文献値 33 物質、phonopy との照合 (上記「検証」)。
- 不具合の修正:
  - ラマンテンソルの形: 4/m, -4, 4, 6/m, 6, -6, 3, -3 の E 系モードでは独立なパラメータが 2 つ
    (3, -3 では 4 つ) あるのに、1 パラメータの形 (4/mmm などの形) を表示していた。形は表から引く
    代わりに、各モードの変位から射影演算子で厳密に計算するようにした。
  - QE 凍結フォノン: 変位 δ を 3N 規格化した基底ベクトルに掛けていたため、原子 1 個あたりの変位が
    1/√(動く原子数) に縮んでいた (大きなセルで力がノイズに埋もれる)。最大原子変位 = δ に変更し、
    使った振幅を manifest.json に記録。
  - 分子: 歪んだ入力の対称化が厳密な群に収束しておらず、残差 (〜1e-7 Å) が変位パターンに残っていた。
  - CIF: 対称操作の記載がない単斜晶で、短い記号 ("P 21/c") のときに格子角 (unique axis) を見ずに
    b 軸設定で展開していた。
  - 結晶のラベル付けで、D2d / S4 の主軸を「最初に見つかった C2 軸」にしており、操作の並び順に
    依存しうる作りだった → 回映軸を主軸にとる。
  - 結晶: 格子定数が検出した対称性と厳密に合わない CIF (例: AsI₃ の菱面体角 51.683/51.683/51.685°)
    では回転行列が直交からずれ、網目モデルの力定数が対称操作と可換でなくなって縮退成分の向きの
    推測 (m>1) が同じ既約表現の別のコピーを混ぜていた → 解析前に格子と座標を検出した対称性に
    理想化 (変化が大きいときはレポートに注記)。
  - 結晶: 網目モデルが隣接セルを ±1 像しか数えておらず、体心・面心・菱面体の primitive セルで
    カットオフ内の隣接原子を取りこぼすことがあった (COD 1010030 I-42m) → 像の範囲をカットオフから決める。
  - 分子: 対称操作探索の基準原子に重心近くの原子が選ばれると、わずかな歪みで対称性を見失う
    ことがあった → 外殻の原子から選ぶ。
  - GUI: VESTA の結合表にない元素の組だけの結晶 (AsI₃ など) で結合が 1 本もないと、3D 表示の
    直前に例外が出て結果が表示されなかった。
- 表示: 分子のラマンテンソル成分が点群の標準の向きで表されていることを注記。

### v2.0 (GUI 版)
- GUI (`vibration_gui.py`) と Windows 配布用 exe のビルド (`build_exe.ps1`) を追加。
- 解析本体をパッケージ `vibration_analysis/` に整理し、計算と表示を分離
  (CLI のコマンドはこれまでどおり使えます)。回帰テストを追加。
- 不具合の修正:
  - 日本語 Windows で直線分子 (CO₂ など) の XSF 書き出しが文字コードエラーで
    停止していた。出力をパイプ/リダイレクトしたときの表示エラーも解消。
  - D₂h / D₂ / C₂ᵥ で C2(z/y/x)・σv(xz/yz) を区別できず、エチレンなどで誤った
    分解 (例「縮退度 3 の B1u」) になっていた。C₂ᵥ では B₂ が出なかった。
  - Th 分子で対称操作を取りこぼし (24 個中 6 個)、自由度が合わない分解になっていた。
    C₃h / C₅h / S6 / S8 でも鏡映・回映の分類と指標表の対応が誤っていた。
  - わずかに歪んだ構造 (実験値・最適化構造) で点群と原子の対応がずれ、
    誤った結果を出していた → 自動で対称化するように変更。
  - 結晶で同じ既約表現が複数回現れるとき、各コピーが対称操作で閉じておらず、
    音響/光学の分離や推測方向が混ざることがあった。網目モデルの推測で
    質量の扱いが分子版と一貫していなかった (一般化固有値問題に修正)。
  - 酸化数付き CIF (例 Ti4+) で QE 入力生成が停止していた。
  - QE 出力の力の読み取りで、verbosity='high' の内訳ブロックを総力と取り違える
    おそれがあった。出力ファイルの欠落も分かりやすいエラーにした。
  - 縮退成分の選び方と、平面分子の面外モードなど網目モデルで決まらない向きが、
    入力ファイルの原子の並び順で変わっていた → 幾何だけで決まる共通規則に変更。
  - 分子: 対称操作のクラス (共役類) を群の積表から求めて指標表と対応させるように
    作り直した。以前は幾何的な推測でクラスを決めていたため、立方群 (Td, Oh) や
    D5, D6d, D7h, D8h, 一部の向きの Cs、原子の並び順によっては D2d で誤った分解になっていた
    (例 Mo(CO)₆, Ni(CO)₄, アダマンタン)。D8h の指標表の誤り (S8 と S8³ の列) も修正。
    割り当てと指標表の整合を正則表現で検査し、不整合なら誤った結果を出さずに停止する。
  - 分子: ほぼ直線の分子 (HNCS など) や細長い分子を直線分子と誤判定し、原子を軸上へ
    動かしていた → 原子が分子軸から許容差以内にあるかで判定。xyz の重水素 (D) を
    H として扱っていた。C2v/D2/D2h の軸の決め方が分子の向きで変わることがあった。
  - 結晶: 光学モードが「重心が動かない」条件 (Σ M u = 0) を満たしていなかった
    (NaCl の T1u で Na と Cl が同じ大きさで動くなど)。
  - 結晶: primitive cell や菱面体軸の CIF で停止していた。直方晶の B2/B3 が数値誤差で
    入れ替わることがあった。mm2・6mm の B1/B2 が Bilbao の慣例と逆だった
    (ウルツ鉱 ZnO は 2B1)。直方晶の Ag・正方晶 (4/m など) の B のラマンテンソルの形が誤っていた。
  - CIF: 対称操作の記載がないとき、H-M 記号の書き方 (`P 21/n` など) や原点の選び方
    次第で誤った構造に展開していた。`Wat` をタングステン、`NH4` をニホニウムと読んでいた。
  - GUI: 解析中に別の解析を始めると結果や保存先の名前が入れ替わることがあった。
    保存の失敗や想定外のエラーが exe では表示されなかった (今はダイアログとログ
    `~/vibration_analysis_error.log`)。設定ファイルが壊れると起動しなかった。
    大きなセルで表示が重かった。左下の軸表示が読み込み直後に古い向きのままだった。
