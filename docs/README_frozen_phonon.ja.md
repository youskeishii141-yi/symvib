# 力ベース Γ点ブロック凍結フォノン (Quantum ESPRESSO 連携)

`factor_group_analysis.py`(因子群解析)で得た対称性適応変位基底を使い、
pw.x の SCF 計算の力から、**ラマン活性モードの Γ点振動数**と
**同じ対称種のコピー間の混合を解いた固有空間**を求めます。
精度は採用した電子状態計算・力の収束・有限変位幅に依存します。縮退した固有空間内の
基底の向きと全体の符号は、QE の力を取り込んでも任意のままです。
計算コストと `ph.x` (DFPT) との優劣は、対象構造・選択したモード・計算条件によります。

## 必要なもの
```
pip install numpy spglib spgrep pymatgen
```
`factor_group_analysis.py` と同じフォルダに置いてください。

## 使い方(2フェーズ)

### フェーズ1: 変位構造の pw.x 入力を生成
```
python qe_frozen_phonon.py generate mycrystal.cif --config qe_config.json
```
- `qe_fp/` に `scf_*.in`(変位させた pw.x 入力)と `manifest.json` が出ます。
- デフォルトはラマン活性モードのみ。全光学モードなら `--include optical_all`。
- 特定の既約表現だけなら `--labels Eg A1g`。
- 変位量は `--delta 0.01`(Å、既定)。δ は「最も大きく動く原子の変位」です
  (対称性適応基底は 3N 次元で規格化されているため、そのまま δ 倍すると原子 1 個あたりの
  変位が 1/√(動く原子数) に減って大きなセルでノイズに埋もれる。v2.1 から最大原子変位 = δ に
  規格化し、使った振幅を `manifest.json` の `amplitudes` に記録します)。

これらを HPC で pw.x にかけます(各 `scf_XXX.in` → `scf_XXX.out`)。

### フェーズ2: 力を回収して振動数を解析
```
python qe_frozen_phonon.py analyze --dir qe_fp
```
- 各 pw.x 出力から力を読み、力定数ブロックを質量計量込みで対角化。
- ラマンピーク一覧(既約表現・振動数・縮退度・テンソル成分)を表示。
- `qe_fp/modes/` に固有ベクトルの XSF(VESTA 用)を出力。縮退した場合は
  `mode_02_Eg_a.xsf`, `mode_02_Eg_b.xsf` のように全成分を保存します。
  Python の返り値では `eigs` が全成分、従来の `eig` は最初の成分です。

### 自己検証(QE 不要)
```
python qe_frozen_phonon.py validate mycrystal.cif
```
合成の対称力定数で、ブロック法が全 3N 対角化と一致するかを確認します。

## 重要な注意
- 本実装は周期境界条件での Γ 点の解析的な力定数部分を求めます。極性絶縁体の
  **方向依存の LO–TO 分裂は含みません**。その計算には Born 有効電荷・高周波誘電率と
  非解析的補正が別途必要です ([Phonopy の定式化](https://phonopy.github.io/phonopy/formulation.html))。
- ブロック分解が正しいためには、構造と質量配置、および計算した力定数が採用した
  対称性を保つ必要があります。音響／光学の識別は質量計量による並進との重なりを使う
  近似判定であり、力の誤差が大きい場合やゼロ振動数の光学モードと混ざる場合は確認が必要です。
- **必ず緩和済み構造(vc-relax)を入力**してください。停留点でない構造の
  「振動数」は物理的意味が薄くなります(数学的には中心差分で曲率は出ます)。
- 力の精度のため **conv_thr は 1e-10 程度**に。
- δ は 0.01〜0.02 Å 推奨(小さすぎると数値ノイズ、大きすぎると非調和混入)。
- 非調和スキャン(ソフトモードのダブルウェル等)に拡張する場合は δ を大きく
  振って V(Q) を多項式フィットします(別ツール ModeMap / CRYSTAL 相当)。

## 計算コストの目安
ラマン分岐の総数ぶんの ±δ 変位(=2×分岐数の SCF)+ 参照1本だけです。
例: 方解石ラマン A1g+4Eg → 9 分岐 → 18 個の変位 SCF + 参照 1 本です。
ブロック化自体は対称性が保たれる範囲で全行列の対角化と等価ですが、有限差分や DFT の
近似誤差を除去するものではありません。
