# 分子振動モード解析 (molecule_vibration_analysis.py)

孤立分子の振動モードを、DFT 計算なしで可視化する教育ツール。
結晶版 (factor_group_analysis.py) と同じ「対称性確定 vs 網目推測」の
哲学を、なじみのある分子で体験できます。分子 → 結晶への橋渡しに。

## 何ができるか
CIF または xyz を入れると:
- 分子点群を自動判定 計45点群 (Cn/Cnv/Cnh/Sn/Dn/Dnd/Dnh の各系列を n=2〜8でほぼ網羅, 立方群 T/Th/Td/O/Oh, 正二十面体群 I/Ih, 直線分子 C∞v/D∞h)
- 内部振動モードを既約表現でラベル付け (Mulliken 記号、直線分子は Σ/Π)
- 各モードの Raman / IR 活性と分極率テンソル成分
- 各原子が「どの方向に動くか」を XSF (VESTA 用) で出力
- m=1 は対称性で方向確定、m>1 は 1/d² バネ網目モデルで推測 (免責付き)

振動数の絶対値は求めません (それは Gaussian / ORCA など量子化学計算へ)。
このツールは「どんなモードがあり、どう動くか」の理解に特化します。

## 使い方
```
pip install numpy spglib pymatgen
python molecule_vibration_analysis.py mymolecule.xyz
python molecule_vibration_analysis.py mymolecule.cif
python molecule_vibration_analysis.py            # 引数なし → 水でデモ
```
→ `modes_<名前>/` に各モードの XSF が出力されます。
VESTA で開き、Properties → Vectors → Show vectors で矢印表示。

## 直線分子 (無限群) の厳密な扱い
CO2 やアセチレンのような直線分子は無限群 (C∞v, D∞h) に属します。
本ツールは、回転角 φ の連続族を数値積分した「真の連続群射影演算子」
P = (l/h) ∫ χ*(R) D(R) で厳密に分解します (有限部分群への近道はしません)。
コードを読む学生が、無限群の大直交性定理がそのまま実装されているのを
見られるよう、理論的厳密性を優先しています。

検証例 (文献値と一致):
- 水 H2O (C2v): 2A1 + B2 (分子面の法線を x にとる Mulliken の推奨)
- アンモニア NH3 (C3v): 2A1 + 2E
- メタン CH4 (Td): A1 + E + 2T2
- CO2 (D∞h): Σg⁺ + Σu⁺ + Πu
- HCN (C∞v): 2Σ⁺ + Π
- アセチレン C2H2 (D∞h): 2Σg⁺ + Σu⁺ + Πg + Πu
- SF6 (Oh): A1g + Eg + 2T1u + T2g + T2u
- C60 (Ih): 2Ag + 3T1g + 4T2g + 6Gg + 8Hg + Au + 4T1u + 5T2u + 6Gu + 7Hu
  (ラマン活性10, IR活性4 — フラーレン分光の標準的帰属と一致)

## 方向の確かさ (結晶版と同じ)
- **対称性確定**: その既約表現が 1 回だけ (m=1) → 群論で方向が一意 (厳密)
- **推測(網目)**: 同じ既約表現が複数回 (m>1) → バネ網目モデルによる推測
  (真の向きは量子化学計算が必要)。例: 水の 2 つの A1 (対称伸縮と変角) は
  混ざりうるので網目推測、B2 (反対称伸縮) は対称性確定。

## 既約分解の正確さ
- 対称操作は自前で探し (pymatgen の操作列挙は Sn, Th で取りこぼすため)、群の積表から
  共役類を求めて指標表の列に対応づけます。C2'/C2'' や σv/σd のように大きさ・回転角が同じ
  クラスは、原子を通る軸・面を C2', σv とする Mulliken の慣例で選びます (ベンゼン D6h で検証)。
- 割り当てと指標表の整合は、正則表現上で各既約表現の射影が射影演算子 (P² = P, tr P = d²)
  になることで確かめ、不整合なら誤った結果を出さずに停止します。
- 複素既約表現を持つ群 (Cn, Cnh, Sn, T, Th) は、複素共役ペアを物理的な 2 次元 (E 表記)
  として扱い、主軸まわりの符号付き回転角で操作を分類して複素指標で重複度を求めます。
- 正二十面体群 (I, Ih) は回転角だけで共役類が決まるので角度で照合します。
- ラマンテンソル成分 (xx, xz, …) は点群の標準の向き (z = 主軸) で表しています。
  入力座標が別の向きでも成分の表記は変わりません (変位は入力座標系で出力)。
- 45 点群すべての指標表について、理想的な群で射影演算子の性質と IR/Raman の割り当て
  (ベクトル表現・対称 2 階テンソル表現の分解) を `tests/test_tables.py` で検証しています。

## 結晶版との関係
同じ「対称性適応モードと真の固有ベクトルの違い」を、分子と結晶の両方で
体験できます。分子で概念をつかんでから、factor_group_analysis.py で
結晶 (周期境界系) に進む、という学習の流れを想定しています。
